# 支付通识 · 一本讲透国内支付的书

一本关于国内支付领域的单文件电子书（`index.html`，双击浏览器打开即可）。

**24 章 / 44 张图表**，覆盖：场景枚举 → 牌照与监管 → 清算结算 → 渠道对接 →
担保交易 → 中台工程 → 风控与资损，外加黑话词典、排查手册、架构师自测三个附录。

> 目标：读完能看懂国内支付全貌，并具备成为支付高级架构师的知识骨架。

## 直接阅读

打开 `index.html` 即可，无需任何依赖；左侧目录可跳章，也支持
`index.html#ch-14` 直接打开某一章。

## 本书特点

- **图表全部由算法生成**（`tools/svgkit.py`）：时序图泳道、连线、文字折行、
  字号缩放都是算出来的，不存在手写坐标导致的错位。
- **时序图零省略**：网联 ↔ 发卡行的"黑盒"交互、日终轧差清算全部画出来。
- **每个概念配真实例子**：麦当劳小程序（商家自有）、抖音电商（平台担保）、
  便利店聚合码（线下收单）贯穿全书。
- **易混概念必有对比**：清算/结算/轧差/划拨四词一张图、无担保 vs 有担保、
  微信 vs 支付宝、即时到账 vs T+1 结算。
- **钱和信息分色**：蓝色箭头 = 信息流，金色箭头 = 资金流。

## 目录结构

```
pay-knowledge/
├── index.html          ← 成品电子书（单文件，直接打开）
├── src/
│   ├── template.html   ← HTML 骨架：样式 + 目录/切章交互
│   ├── cover.html      ← 封面
│   └── parts/          ← 各章正文（HTML 片段，按文件名排序拼接）
└── tools/
    ├── svgkit.py       ← 图表引擎：时序图/流程图/架构图/对比图生成器
    ├── figs.py         ← 全书 44 张图的定义（每图一个函数）
    ├── build.py        ← 构建脚本：parts + figs → index.html
    ├── preview.py      ← 把任意几张图渲染成单页，便于截图巡检
    └── smoke_test.py   ← svgkit 冒烟测试
```

## 怎么改内容 / 改图

**改正文**：编辑 `src/parts/` 里对应章节的 HTML，然后运行构建：

```bash
cd tools && python3 build.py
```

**改图表**：每张图是 `tools/figs.py` 里的一个函数（如 `d6_wx_v3_seq`），
正文里用 `<!--FIG:图名-->` 占位。改函数里的文字/节点后重新构建即可。
布局（泳道宽度、连线位置、文字折行）由 `svgkit.py` 自动计算，不需要手写坐标。

**巡检图表**：`python3 tools/preview.py 图名1 图名2 …` 会把指定图渲染成
`tools/_preview/index.html`，浏览器打开截图即可检查排版。

## 图表着色约定（全书统一）

- **蓝色箭头** = 信息流（指令/报文）
- **金色箭头** = 资金流（钱真的在动）
- 红色 = 风险/异常，绿色 = 正常/通过，紫色 = 清算机构，金色底 = 银行
